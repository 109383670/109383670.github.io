# 中国民间信仰详细调查报告

## 信仰谁 · 怎么信 · 怕什么 · 在哪信

---

## 使用说明

民间信仰不是宗教——没有创教者、没有经典、没有教会组织。它是一套叠加在儒释道之上的生活化信仰系统，渗透在婚丧嫁娶、岁时节庆、建房动土、生病求医的每一个日常决策里。

本报告与已完成报告互补：儒家报告覆盖丧祭礼制，道家报告覆盖道教神谱，佛家报告覆盖轮回因果，鬼怪谱系覆盖鬼怪类型，神仙谱系覆盖官方神谱。本报告聚焦**民间实际信仰的混杂形态**——佛道儒与原始巫术融合后，在基层社会的真实面貌。

# 上篇·信仰谁

## 第一章 祖先崇拜

### 1.1 核心逻辑

| 字段 | 内容 |
|------|------|
| **本质** | 死去的祖先并未消失，而是转化为另一种存在继续影响生者 |
| **伦理基础** | "身体发肤受之父母"——生命是父母给的，欠祖先的债永远还不完 |
| **祭祀动机** | 不祭→祖先不安→降祸子孙；祭→祖先保佑→家族兴旺 |
| **"无后"恐惧** | "不孝有三无后为大"——无男性后代=无人祭祀=祖先永远挨饿 → 最严重的不孝 |

### 1.2 祭祀载体

| 载体 | 内容 |
|------|------|
| **祠堂** | 家族祠堂——供奉始祖以下历代祖先牌位，家族公共祭祀空间。南方（闽粤赣客家人）祠堂文化最盛 |
| **牌位** | 木制灵位——上书"某某公之神主"，供奉于祠堂或家中神台。一个牌位=一个祖先的"住所" |
| **家谱** | 记录家族世系传承——修订家谱是家族大事，通常三十年一修。家谱=祖先的"户口本" |
| **祖坟** | 墓地——风水选址至关重要（关乎子孙兴旺）。清明扫墓是最大祭祖活动 |

### 1.3 祭祖时节

| 时间 | 节日 | 方式 |
|------|------|------|
| **除夕/春节** | 年祭 | 家中神台前摆供品、上香、磕头——请祖先回来过年 |
| **清明** | 扫墓 | 墓前祭扫——除草、添土、供食、烧纸钱 |
| **中元（七月十五）** | 鬼节 | 烧纸钱、放河灯——祖先可回家接受供养 |
| **冬至** | 冬至祭祖 | 祠堂祭祖——南方尤其重视 |
| **忌日** | 祖先死亡日 | 家中祭祀——个别纪念 |

### 1.4 祭祀仪式结构

```
上香（请神降临）
  ↓
摆供（饭菜酒水果品）
  ↓
叩拜（磕头——次数有讲究）
  ↓
祝祷（口中念请祖先保佑）
  ↓
烧纸钱（供祖先在阴间使用）
  ↓
撤供（供品家人分食——分享祖先福荫）
  ↓
送神（鞭炮或默念送祖先归去）
```

## 第二章 天地自然崇拜——基层空间神谱

### 2.1 家宅神灵

| 神灵 | 职能 | 祭祀方式 |
|------|------|----------|
| **灶神**（东厨司命） | 监督一家善恶，年底上天汇报 | 腊月廿三/廿四祭灶（详见第六章） |
| **门神** | 守护家宅门户，驱邪入户 | 春节贴门神像（秦叔宝、尉迟恭或神荼、郁垒） |
| **土地公**（福德正神） | 守护一方土地，保佑家宅平安 | 家中或村口土地龛，初一十五上香 |
| **床母** | 守护床铺——保佑睡眠和生育 | 床头暗祭，不设像 |
| **井神** | 守护水源 | 初一十五祭井——不往井中扔污物 |
| **厕神**（紫姑） | 守护厕所——占卜吉凶 | 正月十五迎紫姑 |
| **仓神** | 守护粮仓——保佑丰收 | 仓库设龛 |

### 2.2 社区神灵

| 神灵 | 职能 | 层级 |
|------|------|------|
| **土地公** | 最基层——一村一地的守护神 | 村级 |
| **城隍** | 城市守护神——冥间地方官 | 县/府/都城隍三级 |
| **龙王** | 掌管水雨——祈雨对象 | 河流/湖泊/海域 |
| **山神** | 守护山脉——猎人和樵夫祭拜 | 山区 |
| **瘟神** | 掌管疫病——送瘟船仪式 | 区域性 |

> 城隍是民间信仰中最特殊的神——他既是阳间的守护神，又是阴间的行政官。城隍庙中的"审案"场景，反映了民间对"阴间司法"的想象。

### 2.3 天公崇拜

| 字段 | 内容 |
|------|------|
| **天公** | 玉皇上帝——民间最高神（非道教的玉皇大帝，虽名字相同但民间理解不同） |
| **天公生** | 正月初九——天公诞辰 |
| **祭天公** | 摆供桌于天井或院子，面朝天空，五牲六斋，从子时开始祭拜 |
| **民间逻辑** | 天最大，天管一切——天公是天的人格化 |

# 中篇·怎么信

## 第六章 灶神与岁末祭祀

### 6.1 灶王爷

| 字段 | 内容 |
|------|------|
| **全称** | 东厨司命九灵元王定福神君 |
| **职能** | 监督一家一年善恶，腊月廿三/廿四上天汇报 |
| **形象** | 朴实老者——贴在灶台上方 |
| **"一家之主"** | 民间认为灶神是每家每户的"驻户神"——比任何神都近 |

### 6.2 祭灶仪式

| 步骤 | 内容 |
|------|------|
| **时间** | 腊月廿三（北方）或廿四（南方）——"小年" |
| **供品** | 糖瓜（麦芽糖）——粘住灶王嘴，让他上天不能说坏话 |
| **对联** | "上天言好事，下界保平安" |
| **仪式** | 撕下旧灶王像烧掉（送神），除夕贴新像（接神） |
| **逻辑** | 贿赂神明——用糖粘嘴=最直白的民间智慧 |

### 6.3 岁末祭祀链

```
腊八（十二月初八）——粥，佛道混合，年节开始
  ↓
腊月廿三/廿四——祭灶，送灶王爷上天
  ↓
腊月廿四——扫尘，大扫除（扫去一年晦气）
  ↓
除夕——贴春联门神、祭祖、年夜饭、守岁、放鞭炮
  ↓
正月初一——拜年，拜神，开门红
  ↓
正月初五——迎财神
  ↓
正月初九——拜天公
  ↓
正月十五——元宵节，年节结束
```

## 第八章 风水堪舆

### 8.1 两派

| 派别 | 特点 | 侧重 |
|------|------|------|
| **形势派**（峦头派） | 看山形水势——龙脉、砂、水、穴 | 地形地貌——肉眼可见 |
| **理气派**（罗盘派） | 用罗盘测方位——八卦、五行、二十四山 | 方位推算——需要工具 |

> 实际操作中两派合一——先看形势（大环境），再用罗盘定方位（精确布局）。

### 8.2 阴宅风水（坟墓）

| 要素 | 内容 |
|------|------|
| **龙脉** | 山脉走向——龙的脊梁。寻龙=找好山势 |
| **穴位** | 龙脉结穴处——安坟的具体位置 |
| **砂** | 穴位周围的山——左青龙、右白虎、前朱雀、后玄武 |
| **水** | 水流——"山管人丁水管财"，水=财 |
| **明堂** | 穴前开阔地——越大越吉 |
| **核心逻辑** | 坟墓风水影响子孙后代——祖先骸骨吸收地气→传递给子孙 |

### 8.3 阳宅风水（房屋）

| 环节 | 禁忌 |
|------|------|
| **选址** | 不选低洼、不选路冲、不选庙前庙后 |
| **动土** | 选吉日，祭土地公，不可冲太岁方 |
| **上梁** | 选吉日吉时，梁上挂红布、写"上梁大吉" |
| **搬家（入宅）** | 选吉日，带米（衣食）、火（旺气）先进门 |
| **门向** | 不正对路、不正对别人家门、不正对厕所 |
| **床向** | 不正对门、不背对窗、不在梁下 |
| **镜子** | 不正对床、不正对门、不正对灶 |

| 东（震） | 甲、卯、乙 |
| 东南（巽） | 辰、巽、巳 |

| 西南（坤） | 未、坤、申 |
| 西（兑） | 庚、酉、辛 |
| 西北（乾） | 戌、乾、亥 |

## 第九章 占卜算命

### 9.1 命理类

| 方法 | 内容 | 特点 |
|------|------|------|
| **八字（四柱）** | 年月日时各二干支=八字，推算命运 | 最普及——"算命"的代名词 |
| **紫微斗数** | 以出生时间排星盘，推算命运 | 最精密——"帝王之术" |
| **骨相/称骨** | 按出生年月日时查"骨重" | 最简单——二两一到七两一 |
| **生肖算命** | 十二生肖+五行 | 最流行但最粗糙 |

### 9.2 卜筮类

| 方法 | 内容 |
|------|------|
| **六爻** | 掷六次铜钱得卦——结合爻辞断吉凶 |
| **梅花易数** | 以时间/数字/方位起卦——邵雍创 |
| **奇门遁甲** | 以时间方位排盘——"帝王之学"，军事/商业用 |
| **抽签** | 寺庙道观抽签——上上签到下下签 |
| **测字** | 写一个字，拆解笔画断吉凶 |
| **鸟卦** | 让鸟叼签——街头算命 |

### 9.3 相术类

| 方法 | 内容 |
|------|------|
| **面相** | 五官形状位置——"天庭饱满地阁方圆"=福相 |
| **手相** | 掌纹——生命线、智慧线、感情线、事业线 |
| **骨相** | 头骨形状——摸骨算命 |
| **痣相** | 痣的位置——"面无善痣" |

### 9.4 解梦

| 方法 | 内容 |
|------|------|
| **传统解梦** | 《周公解梦》——查表式对照 |
| **反梦** | 梦凶=现实吉，梦吉=现实凶 |
| **直梦** | 梦见什么=现实发生什么 |

## 第十章 巫术与驱邪

### 10.1 驱邪物品

| 物品 | 驱邪原理 | 使用方式 |
|------|----------|----------|
| **桃木剑** | 桃木驱鬼——后羿被桃木棒打死，鬼畏桃木 | 悬于门上或随身 |
| **八卦镜** | 反射邪气——镜面反射 | 挂于门楣或窗上 |
| **镇宅石** | 石头稳重——镇压邪祟 | 埋于门槛下 |
| **泰山石敢当** | 泰山石=最硬=最镇——刻字立于路冲 | 立于丁字路口冲处 |
| **照妖镜** | 铜镜照出鬼怪原形——鬼怕被看见 | 挂于门上 |
| **鸡血** | 鸡鸣破晓=阳气回升——鸡血驱阴 | 涂于门框、器物 |
| **朱砂** | 红色=阳气——辟邪 | 画符、点额、撒墓 |
| **艾草** | 药用+驱邪——端午悬门 | 悬于门上、做成香囊 |
| **雄黄** | 矿物——驱蛇虫辟邪 | 端午酒中加入、涂额 |
| **黑狗血** | 黑狗通灵——血辟邪 | 泼洒驱邪 |
| **狗牙** | 天狗咬九头鸟——鬼怕狗 | 做吊坠给小儿佩戴 |

### 10.2 驱邪仪式

| 仪式 | 内容 |
|------|------|

## 第十四章 民间信仰的现代演变

### 14.1 神台合一

现代家庭最常见的神台布局：

```
┌─────────────────────────┐
│  观世音菩萨像（中·最高）  │ ← 佛教
│  财神像（左）             │ ← 道教/民间
│  祖先牌位（右）           │ ← 儒家/祖先崇拜
│  桔子（吉）/苹果（平安）   │
│  香炉                     │
└─────────────────────────┘
```

> 三教合一不在寺庙里，在普通人家神台上完成。观音、财神、祖先并排供奉——民间不管教义冲突，只管灵不灵。

### 14.2 传统的新形态

| 传统 | 现代变体 |
|------|----------|
| **烧纸钱** | 电子烧纸（APP）、冥币面额越印越大、纸扎做iPhone/别墅/跑车 |
| **算命** | 网络算命（八字APP）、AI塔罗、星座（西方传入但本土化） |
| **拜太岁** | 寺庙拜太岁排队+小程序预约、线上拜太岁 |
| **求签** | 电子求签机、微信求签 |
| **风水** | 房地产风水顾问、装修风水指南、办公室风水布局 |
| **祈福** | 寺庙新年头香（拍卖）、电子祈福墙 |
| **本命年** | 红绳手链（时尚化）、红内衣品牌营销 |

### 14.3 寺庙商业化

| 现象 | 内容 |
|------|------|
| **门票经济** | 大型寺庙收门票——少林寺、灵隐寺、法门寺 |
| **香火经济** | 高价香——寺庙指定购买 |

| 态度 | 表现 |

### 14.5 非遗保护与民间信仰

| 字段 | 内容 |
|------|------|
| **政策** | 民间信仰活动作为"非物质文化遗产"保护——庙会、祭祀、节庆 |
| **矛盾** | 非遗要求"原真性"，但民间信仰本身是活的、变的、混杂的 |
| **效果** | 部分信仰活动因非遗保护获得合法性和资金——如妈祖祭典、关公信俗 |
| **风险** | 被遗产化=被博物馆化——从生活实践变成表演 |

## 附录一：民间信仰核心特征

| 特征 | 内容 |
|------|------|
| **无经典** | 没有统一的经典文本——靠口耳相传和习惯 |
| **无教会** | 没有统一的教会组织——每个社区、每个家庭自行操作 |
| **实用性** | "灵就拜，不灵就换"——信仰以灵验为核心标准 |
| **混杂性** | 佛道儒巫不分——观音和财神并供，不问教义冲突 |
| **在地性** | 一方水土一方神——地域差异极大 |
| **生活化** | 信仰渗透在日常——不是周末去教堂，是每天生活的一部分 |
| **恐惧驱动** | 很大程度上由恐惧驱动——怕鬼、怕死、怕穷、怕病、怕灾 |

## 附录二：民间信仰与制度宗教对比

| 维度 | 民间信仰 | 佛教/道教 |
